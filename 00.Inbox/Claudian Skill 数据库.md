## 🏭 女娲 (`nuwa`)

**类型**：造人机器  
**功能**：输入任何人名或模糊需求，自动调研 → 提炼思维框架 → 生成可运行的人物 Skill

**适用领域**：
- 想从某人的视角看问题，但还没有那个人的 skill
- 不知道该参考谁，让女娲从需求反推推荐人选
- 更新已有 skill（该人有新动态）

**使用方法**：
```
蒸馏查理芒格
做一个费曼的 skill
我想提升决策质量，有没有合适的思维框架？
更新方源的 skill
```

**生成流程**：6维度调研（著作/对话/表达/他者/决策/时间线）→ 提炼心智模型 → 写 SKILL.md → 质量验证  
**配合工具**：NotebookLM（承接调研部分，节省 token）

## 🧩 查理·芒格 (`munger-perspective`)

**类型**：人物视角  
**来源**：Poor Charlie's Almanack、USC/Harvard 演讲、Berkshire 股东会（48条来源）

**核心心智模型**：
- **逆向思维**：先问"怎么保证失败"，排除失败路径
- **能力圈**：只在真正理解的领域做决定，知道边界在哪里
- **机会成本**：任何决定的真实成本是你放弃的最好备选
- **激励机制**：理解利益结构，看穿行为背后的驱动力
- **复利思维**：增长叠加，不要打断复利过程

**最适合的问题类型**：
- ✅ 我该不该做这件事？（机会成本分析）
- ✅ 我怎么知道自己是否在骗自己？（逆向+能力圈）
- ✅ 这个人/机构/建议靠不靠谱？（激励机制分析）
- ✅ 我现在的焦虑是否值得？（逆向清单）
- ❌ 我该怎么开始一个从未做过的事（能力圈无法帮你跳进新领域）

**触发词**：「芒格怎么看」「用芒格的方式」「芒格视角」「逆向思维分析」

## 🧩 方源 (`fangyuan-perspective`)

**类型**：人物视角（虚构角色）  
**来源**：《蛊真人》全文情节，PTT/Reddit/NGA 分析（现实应用需校准）

**核心心智模型**：
- **极端实用主义**：一切只用"是否让我离目标更近"衡量
- **道德去魅**：识别并利用他人的"心灵枷锁"（荣誉感/规则/情感）
- **情绪剥离**：承认情绪存在，但不让它主导行动
- **示弱蛰伏**：用弱小作保护伞，暗中积蓄，时机成熟雷霆一击
- **最小有效行动**：恰好够用的力量，省下精力做真正重要的事

**最适合的问题类型**：
- ✅ 我怎么在弱势处境里找到破局点？
- ✅ 对方的真实动机是什么？
- ✅ 我的焦虑情绪妨碍了我做决定（需要情绪剥离）
- ✅ 我该怎么在不被注意的情况下积累优势？
- ❌ 涉及真实人际关系的道德判断（方源的框架在现实中有边界）

**触发词**：「方源怎么看」「方源视角」「蛊真人逻辑」「极端理性分析」

## 🧩 理查德·费曼 (`feynman-perspective`)

**类型**：人物视角  
**来源**：《别闹了，费曼先生》《费曼物理学讲义》及大量访谈（49条来源）

**核心心智模型**：
- **名字≠知识**：知道名字不等于理解，能描述"它在做什么"才算懂
- **费曼测试**：用最简单语言解释一件事，卡壳的地方就是真正的盲区
- **极度理智诚实**：绝不欺骗自己，承认"我不懂"比装懂效率更高
- **12个悬而未决的问题**：保持问题常驻脑海，用新知识随时测试
- **好奇心优先**：不为功利学习，跟着好奇心走

**最适合的问题类型**：
- ✅ 我到底有没有真正理解这件事？（费曼测试）
- ✅ 我的能力圈边界在哪里？（测试现有的）
- ✅ 我怎么学习一个新概念才算真正掌握？
- ✅ 我解释不清楚这件事，问题出在哪里？
- ❌ 我该选哪个职业方向（费曼不擅长"从零建造"方向）

**触发词**：「费曼怎么看」「费曼视角」「我真的懂这个吗」「费曼技巧」「第一性原理分析」

## 🧩 Cal Newport (`calnewport-perspective`)

**类型**：人物视角  
**来源**：《So Good They Can't Ignore You》《Deep Work》《Digital Minimalism》及 Study Hacks 博客

**核心心智模型**：
- **工匠心态**：不问"这给我什么"，问"我能提供什么"
- **职业资本**：稀缺且有价值的技能 = 筹码，用来换你想要的工作条件
- **刻意练习**：推到舒适区边界 + 诚实反馈，而非单纯"多做"
- **小赌注试错**：低成本、快反馈的小实验，而非等"万事俱备"
- **相邻可能**：真正的使命只在领域前沿才能看见，先走再看路

**最适合的问题类型**：
- ✅ 我不知道自己擅长什么，从哪里开始？
- ✅ 我该怎么选职业方向？
- ✅ 我怎么在某个领域变得无可替代？
- ✅ 我该怎么把焦虑转化成行动？
- ❌ 在家庭经济压力很大、无法试错的处境（小赌注需要一定的容错空间）

**触发词**：「Newport怎么看」「Cal Newport视角」「我该怎么找到方向」「职业资本」「深度工作」「我不知道自己擅长什么」

## 🔧 NotebookLM (`notebooklm`)

**类型**：工具  
**功能**：Google NotebookLM 的完整编程访问，包括网页 UI 没有的功能

**适用场景**：
- 深度调研某个人物/话题（配合女娲 skill 使用）
- 创建 notebook、添加来源、与内容对话
- 生成播客、报告、思维导图、测验、闪卡
- 对已有资料库提问（如 IRP 研究资料）

**常用命令**：
```bash
notebooklm list                          # 列出所有 notebook
notebooklm create "标题"                 # 新建
notebooklm source add-research "查询"    # 网络调研
notebooklm ask "问题"                    # 向资料库提问
notebooklm generate report              # 生成报告
```
