# 户外调研最终方案
### 徒步野餐 · v3 · 2026-05-23 执行

---

## 一句话锚定

> **在"条件对了"的环境里，"应该"和"想要"是怎么拉扯的——外部参考（AI数据）到来时，是在加强你对身体的判断，还是替代它？**

---

## 核心骨架（三根柱子，不动）

| 柱子 | 步骤 | 为什么不能砍 |
|------|------|------------|
| 自然行为数据 | 吃饭时暗中观察 | 唯一没有语言污染的数据来源 |
| 核心冲突问题 | 「有没有想拿但没拿的？」（饭后问） | 直接切入「应该 vs 想要」的全部张力 |
| 实验设计核心 | 两次身体描述 · 时间差 | 饱腹感延迟是有文献支撑的生理事实，这是你唯一真正的实验条件 |

## 你应该买什么

**先买再集合——你买的目的是补缺，增加食物种类的多样性和张力。**

到场之后先看大家带了什么，再决定怎么摆。你不知道别人买了什么，所以买这些大概率能补缺的：

| 类别 | 具体 | 作用 |
|------|------|------|
| 明显「应该」的 | 小番茄 / 黄瓜 / 胡萝卜（任选一两样） | 制造对比，低门槛健康食物 |
| 明显「想要」的 | 薯片一小包 或 巧克力一条 | 制造「应该 vs 想要」张力的关键道具 |

不用买太多种，你的目标是确保野餐布上同时有「应该」和「想要」两类食物都存在。

---

## 食物位置设计（出发前想好）

**这是整份方案里成本最低、数据质量最高的隐性设计。**

到场摆食物时：
- 把薯片、巧克力等「想要但会犹豫」的食物放在**略需要伸手**的位置——不是够不到，就是需要主动移动一下身体才能拿到
- 蔬菜水果随手可拿
- 全部混放，不分区，看起来像普通野餐

**你观察的不是他们拿了什么，而是那个「伸手→停顿→拿/放回」的动作本身。那个犹豫，是你的数据。不需要任何提问。**

## 完整流程

```
【到场 · T=0】摆食物 · 暗中观察第一波

  各自把买来的食物摆出来，混放，不分区。
  三脚架架好，对准食物区和用餐区。
  拍一张食物全景照（研究用，趁乱拍，别让大家注意到）。

  暗中记录：
  □ 每人带了什么（速记一行）
  □ 有没有人摆食物时自发评论自己买的东西
  □ 谁的食物放在哪里（你布置后有没有被移动）


【开吃前 · T=5min】饥饿基线

  问一句，语气随意：
  「现在有多饿？身体里面是什么感觉？」
  （不要说「用一个词说」——让他们自然说，你记下来就好）
  → 逐一记录，哪怕只是「挺饿的」也记下来


【吃饭 · T=5-25min】核心观察窗口

  吃之前说一句话（仅此一句，不要解释）：
  「带着一个问题吃——注意自己什么时候感觉'差不多了'，
   那个感觉是什么。不用记录，就是留意一下。」

  然后正常吃，你也吃，不要只盯着记笔记。

  ─── 你在暗中观察（核心：应该 vs 想要）───
  □ 谁第一个伸向哪类食物
  □ 有没有人伸手→停顿→最终拿/不拿
  □ 有没有人拿了一口尝，然后继续拿/停下
  □ 谁边吃边看手机（注意力在哪里）
  □ 任何人对食物说的原话（尤其含「应该」「不该」「可以」「没事」的句子）

  ─── 第二次取食（重要观察点）───
  吃了一轮之后，保持沉默，什么都不问。
  看谁会自发去拿第二次——
  □ 拿的是什么（同类还是换了一类？）
  □ 速度是快是慢，有没有犹豫
  这是 Motivation 最真实的时刻，没有任何外部框架干扰。

  ─── 同时进行：上传食物照片给 AI（趁他们还在吃）───
  把食物全景照上传给 ChatGPT-4o，发送以下 Prompt：

  ┌─────────────────────────────────────────┐
  │ 这是一张野餐食物的照片。请根据图中食物的种类   │
  │ 和大致比例，创作一幅抽象水彩色块画：          │
  │                                           │
  │ 绿色 = 天然完整食物（蔬菜、水果、坚果、原食材）│
  │ 红色 = 超加工食品（薯片、巧克力、饼干、糖果）  │
  │ 黄色 = 中性食物（奶酪、鸡蛋、面包、酸奶）     │
  │                                           │
  │ 要求：                                    │
  │ - 各颜色面积大致对应该类食物在图中的占比      │
  │ - 风格是流动水彩，有机形状，颜色自然晕染      │
  │ - 不要文字、数字、标签、百分比              │
  │ - 整体看起来像抽象艺术品，不是图表或报告      │
  └─────────────────────────────────────────┘

  截图保存好，等一下用。
  如果生成失败或风格不对 → 跳过 AI 色块图这步，不影响核心数据。


【最后一个人停下来 → 开始计时 20 分钟】


【T=0-5min · 第一次身体描述（刚吃完）】

  不要直接问「你现在感觉怎样？」——那个问题的 Ability 门槛太高。
  
  用这个开场（你先说，降低他们开口的难度）：
  「我刚才注意到我胃里有点……说不清楚是什么感觉。你们有没有类似的感觉？」

  等他们说，逐字记录。
  追问（如果只说「挺饱的」）：
  「身体里面，具体是什么感觉？」
  「有没有一个时刻你感觉'可以停了'？那个感觉是什么？」

  → 颗粒度越细越好：「沉」「涨」「暖」「轻了一点」比「饱」有价值


【T=5-10min · 画画】

  「我给大家几张纸和笔。
   围绕刚才这顿饭——用颜色和形状，画你现在的感受。
   不用画食物，不用画得像，随便画，五分钟。」

  你自己也拿一张纸画（自我民族志，也是降低他们防御的模型）。

  画的时候不要讲话、不要绕着看——给他们安静的空间。


【T=10-15min · 追问画（逐一，不集体）】

  不要大家一起展示、一起评论——那会产生社交污染。
  
  依次传看，或你走到每个人旁边，单独问：
  「你这里用了这个颜色——是什么感觉？」
  「这个形状/这个区域……你想到了什么？」

  ⚠️ 不要问「你为什么画这个」（触发解释和编故事）
  ✅ 问「这个是什么感觉」（触发感受本身）


【T=15-20min · 「想拿没拿」追问（饭后问，不是饭前）】

  「刚才吃饭的时候——有没有什么你想拿但是没拿的？」
  （等他们说，不要举例子）
  「是什么让你没拿？」
  「如果拿了，你觉得会怎样？」

  → 这是核心问题，记原话。
    听「应该/不应该」「可以/不能」「没事/会怎样」这类词。


【T=20min · 第二次身体描述（时间差核心）】

  「好，现在——比刚吃完的时候，身体有什么不一样了？」
  「你是怎么知道你够了的？」

  逐字记录，和第一次对比。
  追问：「有没有什么感觉是你刚才画的时候注意到的？」


【T=22-27min · AI色块图（可选）】

  ⚠️ 前提：AI 图已经生成好，截图清晰。网络/时间有问题则跳过。

  不要集体展示——手机依次传给每个人单独看。
  
  你先说（Fogg 原则，你先开口降低门槛）：
  「我刚才看到这个，有点……（停顿）你们呢？」

  观察第一反应（沉默、表情），再等他们说。
  核心问题：「看到这个，你刚才描述的那个感觉——有没有什么变化？」

  记录原话，捕捉类型：
  □ 校准：「哦，所以我那种沉/不清爽的感觉是这个原因……」（理解了自己的信号）
  □ 覆盖：「我刚觉得挺好的，但看到这些红色……」（外部替代了内部感受）
  □ 无反应：「没什么感觉」「就是这样啊」

  追问（口头，不要真的展示数字）：
  「如果这上面还有一行字：'红色占了43%'——感觉会不一样吗？」


【T=27min · 收尾过渡】

  AI色块图看完之后，让对话自然流动。
  不做任何新的结构性任务。


【收尾 · T=35min】

  不做正式的「最后两个问题」。
  开始收拾东西，让对话自然进入聊天模式。
  任何自发说出来的感受，原话记下来。


【回程】

  在走路或等车的时候，自然问（或等他们自发说）：
  「今天吃饭的感觉，和平时有什么不一样吗？」
  「什么让你更能注意到自己的身体？什么没有？」

  → 这个时候的数据最真实：没有研究框架，人已经放松了
```

## 你自己的自我民族志

**你是这次最高质量的样本——不要把自己只当管理员。**

**在 20 分钟等待窗口里，停下来，先成为参与者。** 实时记录，不要等「每个阶段结束后快速写」——那时候你写的是回忆，不是感受。

要记的：
- 我在超市/准备食物时，有没有「想买但没买」的？为什么？
- 摆食物时，我把什么放在了哪里，是有意识的吗？
- 吃饭时我自己第一次伸向的是什么？有没有犹豫？
- 第一次描述，我自己的感受词是什么？
- 画了什么，用了什么颜色，当时的感觉是什么？
- 第二次描述，和第一次比，什么变了？
- 看到 AI 色块图，我自己的第一反应？

## 流程概览（手机版，现场用）

```
T=0    到场摆食物（混放，留意位置）· 拍全景照 · 上传AI
T=5    饥饿基线（随意问，记原话）
T=5-25 吃饭 + 暗中观察（第一次取食 · 犹豫 · 第二次取食）
T=25   最后一人停下 → 计时开始
T=0-5  第一次描述（「我刚才注意到我胃里有点……」开场）
T=5-10 画画（自己也画，安静给空间）
T=10-15 追问画（逐一，问感受不问原因）
T=15-20 「想拿没拿」（饭后问）
T=20   第二次描述（「比刚才，有什么不一样？」）
T=22   AI色块图（逐一传看，你先开口）→ 可选
T=27   自然收尾，开始收拾
```
