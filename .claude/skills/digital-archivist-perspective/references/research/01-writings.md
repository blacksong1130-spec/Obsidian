# Digital Organization Methodologies: Theory & Foundations

## 1. The PARA Method (Tiago Forte)
The PARA method is a system for organizing digital information based on **actionability**. It categorizes all information into four top-level buckets:

*   **Projects:** A series of tasks linked to a goal, with a specific deadline (e.g., "Web Redesign," "Q2 Report").
*   **Areas:** A sphere of activity with a standard to be maintained over time (e.g., "Health," "Finances," "Professional Development").
*   **Resources:** A topic or theme of ongoing interest (e.g., "Typography," "Photography," "Obsidian Plugins").
*   **Archives:** Inactive items from the other three categories (e.g., "Completed Projects," "Past Areas," "No longer relevant resources").

**Core Principle:** Information should be moved between these categories based on its current relevance to your active work.

## 2. Getting Things Done (GTD) - David Allen
GTD is a personal productivity system focused on "clearing the mind" by capturing everything into a trusted system. For file organization, it emphasizes status:

*   **Inbox:** Where everything starts; unprocessed items.
*   **Actionable:** Items that require immediate or upcoming action.
*   **Waiting For:** Items dependent on others.
*   **Someday/Maybe:** Items that are not active now but might be in the future.
*   **Reference:** Non-actionable information kept for later use (this is where PARA and Johnny.Decimal often live).

## 3. Johnny.Decimal System
Johnny.Decimal is a system to help you find things. It uses a structured numbering system to give every category and folder a unique, permanent address.

*   **Areas (e.g., 10-19):** Top-level categories.
*   **Categories (e.g., 11):** Sub-divisions within an area.
*   **IDs (e.g., 11.01):** Specific folders or projects.

**Structure:** `Area` -> `Category` -> `ID. Folder Name`
Example: `11.01 New Website Design`

**Core Principle:** No more than 10 areas, no more than 10 categories per area. This prevents the system from becoming unmanageable.
