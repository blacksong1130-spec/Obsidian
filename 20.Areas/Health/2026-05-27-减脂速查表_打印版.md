# 减脂速查表（打印版）

---

## 每天吃什么

### 🥣 餐1 — 早餐（固定，每天一样，永不跳过）

| 食材 | 份量 |
|------|------|
| 燕麦（含葡萄干） | **100g**（训练日） / **70g**（休息日：周三、周日） |
| 牛奶 | **300ml** |
| 冷冻水果（蓝莓/车厘子/菠萝任选） | **150g** |
| 鸡蛋（全蛋） | **4 个** |

---

### 🍌 早上流程（顺序固定）

| 步骤 | 做什么 | 说明 |
|------|--------|------|
| ① 起床后 | **燕麦（餐1）** 在家吃完 | 先吃饱，训练有力气 |
| ② 45–60min后 | 出门去健身房 | 燕麦消化窗口 |
| ③ 健身房 | 力量训练 **60–65min** | 主课 |
| ④ 力训后 | **爬楼机 40min** | |
| ⑤ 爬楼机后立刻 | 香蕉 **1根** + 蛋白粉 **1勺** + 肌酸 **5g** | 快碳+蛋白，修复窗口 |
| ⑥ 同一次 | **健身房洗澡** | 解决"洗两次"问题 ✅ |
| ⑦ 出门 | 去咖啡店 / 学校 / 直接回家 | 一天只洗这一次就够 |

> 晚上有空且方便 → 再去健身房爬楼机 40min（bonus）
> 晚上有事 → 直接跳过，不需要再洗澡，早上已搞定一切

---

### 🥩 餐2 / 餐3 — 主餐（看你在哪儿）

|------|-------|

> 咖啡店只吃5个蛋，**不用补鲭鱼**，因为晚上还有牛排。

| 食堂 | **鸡腿饭，米饭只吃半碗** |

## 每周训练安排

| 天 | 🌅 早上（必做） | 🌙 晚上（有空就做） |
|----|--------------|-----------------|
| 周一 | 胸/肩/三头 → 爬楼机 40min | 爬楼机 40min ✨ |
| 周二 | 背/二头+核心 → 爬楼机 40min | 爬楼机 40min ✨ |
| 周三 | 🚶 户外散步 30min（不进健身房） | — |
| 周四 | 腿（深蹲/腿举/臀推）→ 爬楼机 40min | 爬楼机 40min ✨ |
| 周五 | 全身复合 → 爬楼机 40min | 爬楼机 40min ✨ |
| 周六 | 轻训（可选）→ 爬楼机 40min | — |
| 周日 | 🛌 完全休息 | — |

> ✨ 晚上爬楼机 = bonus，做了多减，没做不亏，早上已完成全部必要训练。
> ✨ 晚上去的话不需要再洗澡（早上健身房已洗），做完直接回家。

### 🍊 睡前（每天固定，三种场景都一样）

| 食材 | 份量 |
|------|------|
| 橘子 | **2个**（减脂期优先） / 最多3个 |

> ✅ 橘子低GI（约40），高纤维，不会大幅拉高血糖。
> 睡前吃碳水影响减脂是误解——**总热量缺口才是关键**，2个橘子约120 kcal，完全在预算内。
> 维生素C还能帮助夜间肌肉修复。**保留这个习惯，不用改。**

## 3条规则（记这3条就够）

> **① 早上流程雷打不动：燕麦（在家）→ 力训 → 爬楼机 → 蛋白粉+肌酸+香蕉 → 洗澡（健身房）→ 出门**
>
> **② 晚上牛排永远都要吃，无论今天在哪儿吃了什么**
>
> **③ 晚上有空就爬楼机，没空不愧疚，早上已经赢了**

## 每日热量速估

| 场景 | 摄入热量 | 运动消耗（双爬坡日）| 净缺口 | 蛋白质 |
|------|---------|-----------------|-------|-------|
| 在家（2餐 + 运动营养 + 橘子）| ≈ 2050 kcal | ≈ −1000 kcal | **≈ −1500 kcal** | ≈ **155g** ✅ |
| 咖啡店（3餐 + 运动营养 + 橘子）| ≈ 2250 kcal | ≈ −1000 kcal | **≈ −1300 kcal** | ≈ **185g** ✅ |
| 学校食堂（3餐 + 运动营养 + 橘子）| ≈ 2350 kcal | ≈ −1000 kcal | **≈ −1200 kcal** | ≈ **185g** ✅ |

> 双爬坡日（早40min + 晚40min）+ 力训 ≈ 消耗1000 kcal。每周减脂速度 **≈ 1–1.2 kg**。
